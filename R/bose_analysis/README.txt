Functions overview:
- Maxwell_fit function: needed in StressRelax_curveFitting_v1. Performs maxwell fit

- Plotting_LoadTime: Plots data check plots for bose data. xvar and yvar can be chosen. Versatile!

- Butterworth_filtering_v1: filters noisy bose signal

- Emod_analysis_v1: Calculates E-modulus from bose output

- Load_config_functions_v1: loads yaml file, sets fontsize, color and loads function from R_function folder (basics and theme)

- StressRelax_curveFitting_v1: performs 1- and 2- element maxwell model fit to stress relaxation data

- StressRelax_pre-processes_tHalf_v1: calculates tHalf of stress-relaxation data
